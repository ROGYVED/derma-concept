# Derma Concept

Landing page institucional em React + Vite para estética premium.

## Tech stack

- React
- Vite
- CSS customizado

## Estrutura

- `src/App.jsx` — estrutura principal da landing page
- `src/main.jsx` — bootstrap da aplicação
- `assets/css/style.css` — estilos visuais da marca
- `vite.config.js` — configuração do Vite

## Como rodar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o ambiente de desenvolvimento:

```bash
npm run dev -- --host 0.0.0.0
```

3. Acesse:

```text
http://localhost:3000
```

## Build de produção

```bash
npm run build
```
